SKDESIGN Kalkulator - PWA starter
Cara pakai:
1. Ekstrak ZIP.
2. Untuk pemasangan PWA dan mode offline penuh, unggah folder ini ke hosting yang memakai HTTPS (contoh GitHub Pages/Netlify).
3. Buka URL di Chrome Android > menu ⋮ > Tambahkan ke layar utama / Install app.
4. Setelah aplikasi dibuka dan file tersimpan di cache, fitur kalkulator dapat dipakai offline.
5. Semua daftar produk dan riwayat disimpan di localStorage perangkat/browser. Tidak ada login atau server database.
Catatan: membuka index.html langsung dari file manager dapat berfungsi untuk kalkulasi, tetapi install PWA/service worker memerlukan HTTPS atau localhost.
